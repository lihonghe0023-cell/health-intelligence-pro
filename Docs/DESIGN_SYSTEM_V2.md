# Health Intelligence Pro · 视觉与 UX 最终设计规范 v2

> 设计冻结基线。所有颜色、按钮、动画、图表和状态不得由执行者自行另开风格分支。概念图仅是视觉目标，所有数字标有“概念演示数据”，不能用作真实运行截图。

## 视觉原则

**Medical Precision × Calm Technology**：轻量级医疗仪器风格、苹果原生语义、少量玻璃质感与柔和曲线。拒绝会遮挡健康读数的粒子、大面积高亮、持续跳动、假 ECG 动画以及为了炫酷牺牲性能的模糊。

## 精准排版

- 首屏品牌角标 11pt Semibold Tracking 2；标题系统大标题 32–34pt Rounded Bold；指标数值 28–36pt Rounded Bold + 等宽数字。
- 模块标题 20pt Semibold；卡片指标名 13–14pt Medium；辅助说明 11–13pt；禁止以 9pt 阅读文本承载重要医疗警示。
- 系统 Dynamic Type，不写死内容高度；视图在 A11y XXXL、加粗文本、深色模式、高对比度下不得裁剪。
- 所有阈值、单位、测量日期、来源均独立可见；每屏专注单一首要任务。

## 布局、按钮、动效与图标

- 手机首屏：品牌 + 时间 → 数据摘要 Hero → 4 张核心生命体征 → 睡眠 → 健康观察；核心操作两次点击内完成。
- 底部五 Tab：今日、心脏、睡眠、健康库、报告；“设置”放今日右上角避免第六 Tab。
- 统一卡片圆角 23pt、卡片内边距 18pt、卡片间距 12pt、分区间距 22pt；内容左右安全边距 18pt。
- 主按钮最小高 48pt、圆角 16pt；每种可操作元素最小 44×44pt，有禁用、加载、成功、失败、重试、离线六态。
- 动效：按钮压下缩放 0.985/140ms，指标数值 `.numericText()`，页面过渡遵循系统导航；没有无限循环闪光。Reduce Motion = 关闭位移/缩放和非必要进场动画。
- 主交互色不依赖颜色独立表达状态；所有红色与绿色状态配文字和 SF Symbols。
- 图标：统一 SF Symbols 语义词典；心率 `heart.fill`、HRV `waveform.path.ecg`、睡眠 `moon.zzz.fill`、呼吸 `lungs.fill`、档案 `cross.case.fill`。品牌 App Icon 使用 `Assets.xcassets` 1024px，无第三方版权 UI 素材。
- 深色：OLED 背景低亮，不用纯白大面积高亮，紧急信息才用高优先级对比。

## 触觉反馈（不滥用）

- 成功保存使用 `.success` 反馈；危险删除使用 confirmation 而不是震动惊吓；普通 tab 切换默认不触觉；HealthKit 后台读取不发触觉。
- Watch 只有主动完成的记录、特定系统允许的高优先级通知才震动。不得伪造医疗报警机制。

## 每个页面的六种状态

1. 数据正常：呈现真实值、单位、时间、来源、可达详情。
2. 未授权：解释为什么需要，提供再次请求/前往系统设置路径，不声明“拒绝”。
3. 无数据：`—` + 可执行建议；不填模拟数值。
4. 加载：渐进式占位、不阻断整个导航。
5. 错误：显示发生在哪一层（HealthKit、磁盘、导出、签名），给明确重试。
6. 异常/陈旧：显示上次记录时间和来源，不当成实时监控。

## 重点屏幕验收设计

- **首页**：一句健康概览来源于数据，不写“健康稳定”除非客观可验证；摘要卡片不会遮挡下面的健康数据。
- **心脏**：心率、RHR、HRV、ECG 样本、已记录系统通知独立区块；ECG 波形来自 HealthKit 原始电压，只读、不夸大临床解释。
- **睡眠**：真实 REM/Deep/Core/Awake 图表，跨来源数据去重；夜间体征和呼吸扰动另外显示。
- **健康库**：可以搜索全部指标，录入血压、血糖、体重和本地笔记，保留日志删除功能。
- **报告**：必须显示报告生成时间、数据来源、数据缺失与免责声明；分享需要用户主动触发。
- **Watch**：首屏心率与 4 项重点体征，睡眠辅助区，原生按钮；46mm 与 42mm、常亮/暗屏测试。
- **设置**：本地隐私、HealthKit 授权解释、数据清除、签名情况、离线说明。

## 验收门槛

VoiceOver 100% 有名字和提示；无按钮只显示而无动作；30 秒内完成首次授权操作路径；冷启动、刷新、图表、PDF 分享、Watch 小屏和 Reduce Motion 有录像/截图；对比真实设备回归后才能定稿。一次设计冻结不意味着以后永远不需要适配苹果系统更新。

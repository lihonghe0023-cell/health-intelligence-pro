# 健康中枢 1.0 完整产品设计（GPT 负责方案，Muse 负责实施）

## 1. 产品定位

- 用户：主要为个人日常健康数据管理，非运动健身软件。
- 设备：iPhone + Apple Watch 双端独立可用、协同管理。
- 主界面优先：心脏、睡眠、体征、健康报告。步数和运动信息作为二级指标。
- 中文优先，系统原生 SwiftUI，无强制账号注册，离线可用，隐私默认保护。
- 视觉：青黛 `#274E5C`、象牙白/系统色底、暖金点缀，动态暗色模式。健康警示使用语义色，绝不用“健康分数 99”掩盖数据缺失。

## 2. 页面信息架构

1. **总览**：上次采样时间、核心 6 卡、异常趋势的谨慎描述、Apple 健康授权和空数据状态。
2. **心脏**：心率/静息心率/HRV/心率恢复/VO₂max、ECG 分类及可用时的原始波形、异常心率通知事件、趋势图。
3. **睡眠**：睡眠时长与分期、夜间心率/血氧/呼吸、腕温变化、呼吸扰动及系统睡眠呼吸暂停通知记录（受限）。
4. **体征**：32+ HealthKit 量化指标扩展为完整可用目录；血压/血糖/体重手工或第三方来源；手表不直接测血糖/血压。
5. **健康档案**：症状、用药、体检记录、检查单、就诊摘要、个人健康年表；来源及录入者可追溯。
6. **报告**：每日/周/月趋势，可信基线，原始数据、解释、局限和 PDF；未来可选云 AI，独立授权。
7. **设置**：权限细分、数据保留与导出、缓存清理、深浅色、测量单位、数据同步、错误日志与诊断包（不包含个人健康值）。

## 3. watchOS 交互原则

- 首屏不超过 4 核心指标：心率、HRV、血氧、呼吸；数据缺失直接显示“暂无记录”。
- 表盘 Complication/Widget 仅展示经系统支持可持续更新的摘要，不能暗示 24/7 实时心电监测。
- 轻触可跳转 iPhone 对应详情；WatchConnectivity 仅同步非敏感状态，健康测量统一以 HealthKit 为数据真源。
- Haptics 只用于用户明确操作反馈，不生成医学警报假象。
- 默认高对比度、大字体和 VoiceOver；高动态字体需要滚动与布局测试。

## 4. 技术架构

```text
iPhone App (SwiftUI + Charts + HealthKit)
    ├── HealthViewModel → HealthKitRepository (读/写严格区分)
    ├── HealthCore Swift Package (模型、睡眠处理、规则解释)
    ├── JournalStore (本地加密/文件保护；后续迁移 SwiftData)
    ├── PDFReportExporter (用户触发)
    └── WatchStatusReceiver ← WatchConnectivity 时间戳

Apple Watch App (SwiftUI + HealthKit)
    ├── WatchHealthStore (独立授权、读取已有系统样本)
    └── WatchStatusBridge → WatchConnectivity 时间戳

可选二期：用户主动开启的本地或加密 NAS 同步 / 外部 AI 服务
```

## 5. 数据标准

- 每条指标保留 metric ID、采样时间、单位、来源、原值与显示转换关系；未来扩展 UUID/provenance/去重状态。
- 连续采样型/离散样本/累计统计/类别事件/临床记录/人工日志分开建模。
- 血氧和体脂单位 `.percent()` 的数值转换需审计；不能按百分数双重乘以 100。
- 睡眠阶段跨来源重叠：应优先用户选择的数据源、去重 UUID 和覆盖区间；当前代码仅按相同阶段做区间合并，正式版必须补足。
- 医疗级阈值不能无来源硬编码；提醒仅限通用非紧急提示，医疗建议要引用可信指导原则。
- 不以 `requestAuthorization` 调用成功作为“已授权读取全部数据”。

## 6. AI 层（默认关闭）

- 第一层：纯本地可解释趋势摘要，不传网络，开箱可用。
- 第二层：用户逐次同意提交所选的数据摘要；支持敏感字段脱敏，支持删除请求和清除服务端记录。
- 第三层：专业辅助问答，严格不做心电自动诊断、不替代医生、不声称预测心梗或中风。
- 所有结论要能指回原始指标、时间区间、来源和计算方法，明确“数据不足”。
- 不能拿用户上传的 Apple 开发者 P12 证书当 AI API 密钥，也不得传给模型服务。

## 7. 交付与质量门禁

- `xcodebuild` iOS Simulator、watchOS Simulator 双端通过；SwiftPM tests 通过。
- 真机检查授权允许/拒绝/撤回、无数据、区域限制；任何分支不能显示虚构健康值。
- UI 深浅色、放大字体、VoiceOver、权限拒绝和网络不可用测试。
- PDF 不乱码、不截断、单位正确，敏感内容可定位销毁。
- 真实 iPhone IPA 可安装；Watch App 只有取得单独签名授权且实机安装后方可标绿。
- 提供 xcodebuild log、截图、录屏、测试结果、SHA256、构建版本和回滚步骤。

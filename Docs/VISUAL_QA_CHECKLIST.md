# 正式 UI/UX 逐页验收表

**视觉与代码分离审计：** 设计资源是参考，只有 Mac 的真实模拟器或真机截图能证明 SwiftUI 实际呈现。每条由 Muse 提供前后截图、测试机型、版本、结论。

## 各页面必过项

- 首次启动：正式 Logo、隐私说明、可跳过、用户主动选择 HealthKit 授权、授权失败能继续使用本地功能。
- 今日：首页只显示真实指标，心率/HRV/血氧/呼吸卡可以点击查看详情，刷新有进度，功能成功后有明确结果。
- 心脏：ECG 历史可点击读波形；原始电压图谱不能被误读为医学诊断；系统心率通知的“无记录”不等于“正常”。
- 睡眠：REM/核心/深睡/清醒显示正确且总分钟数能对上；夜间体征不是用全日最近读数冒充“夜间平均”。
- 健康库：35 项指标定义搜索流畅；手动血压/血糖/体重成功/失败/输入错误都有反馈；日记增删、重启恢复成功。
- 报告：生成 PDF 没有空白页和文字裁剪；链接可分享、支持取消；无数据时不产生正常/异常诊断结论。
- 设置：权限解释、隐私、导出、数据擦除确认和安装限制说明；本地删除不误删 Apple 健康数据。
- Watch：所有核心数据都有单位、时间、来源提示；睡眠摘要和按钮 42mm 不溢出；没有 NFC/私有传感器等虚构功能。

## 六态 × 关键功能

| 状态 | UI 原则 | 触发测试 |
|---|---|---|
| 初次加载 | 占位+导航仍可使用 | 首次启动，健康库大量样本 |
| 已有数据 | 真实数值+单位+来源+时间 | 与苹果健康逐项核对 |
| 无数据 | `—`、原因和下一步 | 手动清空实验资料或从未录入 |
| 未授权 | 不谎称“已拒绝” | 用户取消授权弹窗 |
| 读取失败 | 错误说明、重试、无残留旧值误导 | HealthKit 抛异常/磁盘异常 |
| 数据陈旧 | 显示日期、区别实时与历史 | 最近一次心率为三天前 |

## 动效与按钮

- 所有触控最小 44×44pt，主要按钮 48pt；不可以出现细小且没有可点击标签的图标。
- 六态完整：普通、按下、禁用、加载、成功、错误；`Reduce Motion` 开启时无必须持续观看的动画。
- 任何运行超过 500ms 的读取交互提供处理中反馈，不阻断返回/导航。
- 心率红色不是默认危险标识，状态必须配文本和来源；图表不使用颜色作为唯一编码。
- Watch 上无持续动画或快速反复震动，不影响电池和正常使用。

## 可访问性

- VoiceOver 可读每个指标的“名称＋值＋单位＋时间/来源”，而不仅是“58”。
- 系统字体放大到最大时，重要文本不裁切、不相互覆盖、不因线条消失。
- 深色与高对比度、减弱透明度、左右滑导航、单手触达、中文繁简和英文长文案测试。
- 44pt 触控尺寸最低线，列表的删除动作与危险清空操作必须双重确认。

## 视觉资产与性能

- AppIcon 1024px、Watch icon 符合苹果尺寸和遮罩要求；由真正的 Xcode asset catalog 编译确认。
- 手机首屏冷启动与滚动帧率实测；避免主线程阻塞；UI 截图必须来自真机/模拟器。
- 所有资源中文无错别字；不使用有版权限制的竞品截图和字体。
- 视觉不能掩盖隐私：图片和宣传稿出现的“92分”“健康稳定”必须标明概念演示或删除。
